# Batch1 EDA: 가설과 특성 선정

선정 근거는 Batch1 46개 셀만 사용한다. 수명은 534~1227사이클, 중앙값 858.5사이클이며 단수명(<500) 0개, 장수명(>1000) 10개다.

Batch2에는 수명 확인 39개 중 단수명 28개가 있다는 분포 관찰만 남긴다. Batch2의 조건·상관계수·오차는 특성·모델 선정에 사용하지 않는다.

| 가설 | Batch1에서 확인한 결과 | 판단 |
|---|---|---|
| 운전조건으로 단수명 구분 | Batch1에는 단수명 셀이 없음 | 이 기준의 분류 검증·선정에 사용하지 않음 |
| Q 급변 피크 크기·이동 | 피크 크기 r=−0.240(p=0.109), 이동 r=−0.226(p=0.130) | 관계가 약해 초기 입력에서 제외 |
| 이른 knee와 짧은 수명 | 안정 knee 45/46개, 수명과 r=+0.827 | 관계는 있으나 후기 기록이 필요해 초기 입력에서 제외 |
| 초기 ΔQ(V) 로그 분산 | Pearson r=−0.886, Spearman ρ=−0.871, 단순 회귀 R²=0.785 | 초기 열화 반응을 관측한 후보로 유지 |

## 로그 지표를 사용한 이유

Batch1 ΔQ(V) 분산은 9.66×10⁻⁶~4.46×10⁻⁴ Ah²로 약 46.2배 차이 난다. 로그는 작은 값의 몰림을 줄이고 초기 전압별 곡선 변화의 불균일성을 읽기 쉽게 한다. target cycle_life는 원래 사이클 단위를 사용한다.

전압 곡선에는 총용량 감소가 뚜렷해지기 전에 셀의 열화가 나타날 수 있어 수명과 연결되는 초기 신호로 해석한다. 상관관계만으로 개별 열화 원인을 확정하지는 않는다. [Severson et al. (2019)](https://web.mit.edu/braatzgroup/Severson_NatureEnergy_2019.pdf)
